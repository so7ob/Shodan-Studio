# الباحث التكيفي — الإصدار 1.5.0

الوضع الافتراضي للمهام الجديدة هو **تقليل الاستعلامات · Adaptive** ضمن
«مهمة جديدة ← إعدادات الجمع والاستكمال». لا يبدأ بتقسيم الدولة ثم المدينة.

1. يقرأ صفحة IP للاستعلام نفسه ويحفظ العناوين فورًا. إذا كانت أعداد الصفوف
   تفسّر الإجمالي المعروض، يكتفي بها. عدد سجلات الخدمات ليس عدد IP الفريد؛
   فقد تتسع صفحة واحدة لنتائج مئات الخدمات على عدد أصغر من العناوين.
2. عند نقص صفحة IP فقط، يفحص مرشحي التقسيم ويقارن عدد الفروع وحجمها وكلفة
   متابعة الفروع الكبيرة. يستطيع اختيار port أو version أو ASN أو country
   أو city أو product أو org أو os. لا يوجد انتقال إلزامي إلى المدينة.
3. يوقف المقارنة عندما تبلغ كلفتها ميزانية التوفير المقدّر، أو يصبح أفضل
   تقسيم قريبًا من الحد الأدنى في نموذج الكلفة. سقف القرار ثمانية متغيرات،
   إضافة إلى حدود الطلبات والعقد القائمة. ترتيب المرشحين أولوية فحص؛ لا
   يعني إنشاء فروع لكل متغير بهذا الترتيب.
4. يفحص IP لكل فرع قبل تقسيمه مجددًا. إذا تغيّرت الأعداد أو كانت فلاتر النص
   متداخلة، يعتمد على الصفحة الفعلية ويحتفظ بتحذيرات تغيّر النتائج.

تظهر آخر خطوة اختارها المخطط في بطاقة التقدم، وتفاصيل المرشحين والأسباب في
تقرير JSON تحت `plan.events`. تحذير نقص صفحة IP الذي عولج بتقسيم كامل يسجل
كحدث `IP_PROBE_RESOLVED`؛ أخطاء التحليل والفروع غير المحلولة تبقى تحذيرات.
تعرض الواجهة تقدم IP بصورة مستقلة، وقد تتغير الخطة والتقديرات أثناء التنفيذ.

## قياسات قابلة للتكرار

هذه **بيانات اصطناعية واختبارات محلية، وليست قياسًا حيًا لاستعلامك**. تساوت
مجموعات العناوين في كل مقارنة، ولم يتصل الاختبار بـShodan أو بالعناوين.

| الحالة | طلبات Priority السابقة | طلبات Adaptive | القرار |
| --- | ---: | ---: | --- |
| 60 عنوانًا | 28 | 1 | IP مباشرة |
| 160 عنوانًا موزعة على 52 مدينة | 55 | 4 | منفذان، فرعان |
| 160 عنوانًا والمنفذ لا يقسمها | 55 | 5 | إصداران، فرعان |
| 160 عنوانًا والدولة هي الأنسب | 55 | 7 | دولتان دون مدن |
| المنفذ ينشئ 52 فرعًا والإصدار ينشئ فرعين | 55 | 5 | اختيار الإصدار |
| 200 سجل خدمة على 50 عنوانًا | 55 | 1 | IP مباشرة |

نجحت 207 اختبارات Python و11 اختبار JavaScript، وفحص الواجهة العربية RTL
بعرضي 375 و1280 دون مخالفات axe في الأجزاء المختبرة. تشمل الاختبارات مقارنة
الكلفة، تغير الأعداد بعد التخطيط، المجموع المجهول، التقسيمات الناقصة والمكررة،
حد العقد، إعادة التشغيل دون طلب الصفحات المكتملة، حفظ IP بعد HTTP 403، واحترام
Retry-After بعد 429. يستخدم API البحث المرقّم مباشرة؛ 160 سجلًا تجريبيًا احتاجت
صفحتين بلا طلبات facets. هذا ليس اختبار قبول حيًا لاستراتيجية Adaptive.

الاختيار تقديري وليس ضمانًا للحد الأدنى لكل استعلام؛ اختبار المتغيرات نفسه
يكلف طلبات. مثلًا، مثال التطبيق التجريبي الأكثر تركيبًا احتاج 11 طلبًا بدل
9 في خطته الجغرافية السابقة. لا يغيّر الوضع صلاحيات Shodan أو ضمان التغطية،
ولا يحاول تجاوز رفض الوصول أو تقييد المعدل.

## الاستكمال والتوافق

المهام القديمة ونقاط حفظها تحتفظ بـPriority أو Tree. لا تُعاد كتابة خطتها
أثناء التحديث. لتجربة المنطق الجديد على استعلام قديم، أنشئ مهمة جديدة بالاستعلام
نفسه واختر Adaptive؛ «نسخ المهمة» يحتفظ بإعداداتها القديمة. تظل النتائج السابقة
متاحة في مهمتها الأصلية. مهام Adaptive الجديدة تستكمل من صفحاتها المحفوظة دون
إعادة الطلبات المكتملة. إعادة التخطيط لا تعتمد على روابط أو أوامر محفوظة.

لم يتغير مخطط SQLite (`user_version=1`). لم تتغير آلية VPN أو المصادقة أو
حماية التسرب، وتبقى مهام المتصفح على النفق والجلسة نفسيهما.

## التحديث والتراجع

راجع [دليل التثبيت](BROWSER_SESSION_AR.md). هذا التحديث يغيّر التطبيق والعامل
فقط؛ تحقّق من توقف العمال عند Checkpoint، وخذ نسخة خاصة من بيانات التطبيق
وإعداداته ووحدات الخدمة، ثم نفّذ `sudo bash install-debian.sh --no-start`
وأعد تشغيل `shodan-studio` فقط. لا يلزم إعادة تشغيل helper أو المتصفح أو VPN.
تُحفظ ملفات المتصفح الحالية كما هي؛ لا تعتمد على أرشفة ملفه الحي كنسخة متسقة.
[دليل النشر الفعلي](planner-evidence/deployment.json) يسجل المسارات والنسخة
الاحتياطية وفحص استعادتها وأعداد البيانات قبل التحديث وبعده.

للتراجع، أوقف المهام واحفظ أحدث بياناتها ثم أوقف خدمة الويب، وأعد رابط
`/opt/shodan-studio/current` إلى `previous_release` المسجل في دليل النشر،
وشغّل خدمة الويب. احتفظ بقاعدة البيانات والنتائج الأحدث؛ لا تستبدلها بنسخة أقدم.
الإصدار 1.4 لا يفهم استراتيجية Adaptive: أبقِ مهامها متوقفة مع نقاط حفظها إلى
حين إعادة 1.5، ولا تحوّل ملفاتها يدويًا إلى استراتيجية أخرى. المهام القديمة
تبقى قابلة للاستكمال بالإصدار القديم.

```bash
python3 -m unittest discover -s tests
python3 tests/benchmark_adaptive.py
node --test tests/test_ip_progress.mjs
python3 tests/serve_vpn_fixture.py --adaptive --port 8797
# من طرفية ثانية، مع Playwright و @axe-core/playwright:
NODE_PATH=/path/to/node_modules node tests/browser_adaptive.cjs http://127.0.0.1:8797
```
