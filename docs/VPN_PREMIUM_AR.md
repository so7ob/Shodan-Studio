# ربط Amnezia Premium بالعامل المعزول

يدعم الإصدار 1.3 مواقع Premium عبر بروتوكول بوابة العميل 5.0.3.0، دون تحريك
واجهة GUI ودون تصدير ملف مستقل لكل موقع. هذا موائم متوافق مع مصدر العميل،
وليس SDK عامة معتمدة من Amnezia. [التصميم والمراجع](VPN_PREMIUM_DESIGN.md).

## التهيئة على هذا الخادم

تحتاج الاشتراك النشط وخانة جهاز فارغة وعميل Amnezia المثبت ببيانات Premium
وقائمة بوابات HTTPS مخزنة. لا تحتاج حذف ملف مستخدم؛ ألغِ فقط ما لم تعد تحتاجه
من لوحة حسابك إن امتلأت الخانات. المدير لا يلغي أجهزة أو ملفات من الحساب.

```bash
sudo apt install python3-cryptography
sudo python3 tools/setup_premium.py --check
# أثناء توقف العامل: قراءة بيانات العميل وربطها بمعرف عامل مستقل.
sudo systemctl stop shodan-studio-vpn
sudo python3 tools/setup_premium.py --apply
sudo systemctl start shodan-studio-vpn
```

أوقف المهمة مؤقتًا وانتظر حفظ Checkpoint قبل إيقاف الخدمة المساعدة. أداة
التهيئة تقرأ المسارات التي تحققنا منها على هذا الخادم فقط:
`/root/.config/AmneziaVPN.ORG/AmneziaVPN.conf` و`/opt/AmneziaVPN/bin/AmneziaVPN`.
لا تعدّل العميل ولا تتصل بالنفق ولا ترسل طلبًا للبوابة. ترفض بيانات غير
متوافقة أو غير مملوكة لـroot بصلاحيات خاصة. لا تُطبع الأسرار عند الفشل.

لإدخال مفتاح اشتراكك من المتصفح بدل استيراده، على إعداد جديد استخدم
`--apply --transport-only` ثم أعد تشغيل المساعد، وافتح **ربط اشتراك Premium**.
يهيّئ ذلك الثقة بالبوابات فقط. لا يُقبل إدخال عنوان بوابة من الواجهة.
الربط يقبل مفتاح اشتراك `vpn://`، وليس ملف دولة مُصدّرًا. يُمسح حقل المفتاح
بعد الإرسال والإغلاق؛ لا يُرجع API المفتاح ولا يحفظه في SQLite أو localStorage.
استخدم HTTPS أو نفق SSH للوصول إلى لوحة الإدارة وفق إعداد الخدمة الحالي.

## اختيار البلد

1. افتح **VPN Manager** ثم **تحديث قائمة Premium**. تميّز الواجهة قائمة
   العميل المخزنة عن القائمة التي تحققت منها البوابة، وتعرض وقت التحديث.
2. ابحث باسم الموقع أو رمزه، ثم اضغط **اتصال**. لا يُعلن النجاح إلا بعد
   Handshake وفحوص DNS/TCP/TLS/HTTPS وعنوان الخروج وحماية التسرب.
3. اختيار موقع آخر يستخدم هوية العامل نفسها، مع زوج مفاتيح نفق جديد.
   لا يستدعي `/v1/native_config` أو واجهات إلغاء الملفات، ولا يحتاج خانة لكل بلد.
4. **تفضيل** يحدد اختيار النماذج فقط. للمهمة اختر Preferred VPN أو VPN Failover
   وقائمة المواقع المسموح بها وحد التبديل. المهام القديمة تبقى Direct.
5. يمكن تعديل الاسم وتعطيل الموقع. دولة Premium تأتي من البوابة ولا تعدّل
   يدويًا؛ مواقع البروتوكولات غير المدعومة تظهر معطّلة.

الدولة المعروضة اختيار من كتالوج الخدمة وليست إثبات GeoIP. عنوان الخروج
مقاس فعليًا من داخل العزل. لا يوجد مصدر إحداثيات جغرافية مهيأ.

## الخصوصية والحدود

- بيانات الاشتراك والهوية وقائمة البوابات في
  `/etc/shodan-studio/vpn/premium.json`، مملوكة لـroot بصلاحية 0600.
  يجب حفظ هذا الملف في النسخة الاحتياطية الخاصة: حذف الهوية وإعادة إنشائها
  قد يستهلك خانة جديدة. الاسم المختصر للجهاز ظاهر للمساعدة على تمييزه.
- HTTPS مع التحقق من الشهادة، وبصمة مفتاح RSA عامة مثبتة بالإصدار، وتشفير
  الطلب حسب العميل الأصلي. لا تحويلات HTTP ولا رجوع إلى HTTP غير المشفر.
  قد تصبح بوابات العميل المخزنة قديمة؛ حدث العميل وقائمته ثم أعد أداة
  التهيئة مع الاحتفاظ بملف العامل وهويته. لا تستبدل بوابات مجهولة يدويًا.
- تنفيذ الاتصال بالبوابة تحت مستخدم مستقل `shodan-vpn-gateway`، دون صلاحيات
  أو مجموعات إضافية، ومحدد بـ28 ثانية. لا يُمنح مستخدم الويب بيانات اعتماد العملية. الاتصال
  بالنفق محصور داخل namespace العامل؛ تبقى SSH واللوحة وGUI على شبكة المضيف.
- أخطاء LIMIT/AUTH/EXPIRED/CAPTCHA/RATE_LIMIT/UPDATE توقف المحاولات مدة
  300 ثانية. لا تُتجاوز CAPTCHA أو حدود الاشتراك بالتنقل بين الدول.
  استجابة إعداد غير متوافقة توقف المحاولة؛ لا يُقبل إعداد أو حقل مجهول.
- عند إنشاء النفق تجرى ثلاثة فحوص صحة كحد أقصى مع انتظار 1 ثم 2 ثانية؛
  لا تُطلب إعدادات جديدة أو هوية جديدة لمجرد تأخر أول Handshake أو DNS.
- لا تغيّر المواقع أثناء تشغيل عامل. أوقفه مؤقتًا وانتظر نقطة الحفظ.
  عند استعادة موقع سابق يُطلب إعداد جديد للهوية نفسها؛ قد تكون البوابة
  أبطلت الإعداد السابق عند محاولة التبديل حتى لو فُقد الرد.
- بعد إعادة التشغيل تبقى الهوية والقائمة والنتائج، لكن لا تدّعي الواجهة
  نفقًا متصلًا بناءً على حالة قديمة. الاتصال التالي يعيد التحقق.

اختبارات الواجهة والمحاكاة لا تثبت نجاح كل دولة. راجع نتائج النفق الحقيقي
وما بقي غير مختبر في [سجل التحقق](VPN_VALIDATION.md).
